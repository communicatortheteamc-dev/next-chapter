# Next chapter — modern wordmark

The current identity uses a precise uppercase grotesk wordmark with deliberate letter spacing. It is paired with a restrained NC signature for the favicon and small brand placements. The previous book/page symbol has been retired.

- `next-chapter-wordmark.svg`: primary charcoal wordmark.
- `next-chapter-wordmark-light.svg`: light wordmark for dark backgrounds.
- `next-chapter-monogram.svg`: compact NC signature.
- `next-chapter-icon-v2.svg`: dark browser icon.

All lettering is outlined SVG artwork, with no runtime font dependency. Wordmark proportions and tracking are set specifically for this identity, using Helvetica Neue outlines. No font files are shipped. Previous asset URLs resolve to the new artwork for compatibility.
